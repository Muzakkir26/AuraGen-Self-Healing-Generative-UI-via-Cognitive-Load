Mathematical Formulations: Quantifying User Friction

1. Hick-Hyman Decision Latency Metric

Ic = b * log2(n + 1) | Flatency = 1 / (1 + exp(-1.2 * (Tobs / Ic - 2.0)))

Evaluates choice entropy across n affordances against reaction time Tobs.

2. Motor Cursor Kinematics & Directional Entropy

cos(θi) = (v1 · v2) / (||v1|| ||v2||) | Jcursor = (1 / (k - 2)) * Σ (θi / π)

High angular deviation with low displacement signals motor hesitation and confusion.

3. Composite Extraneous Cognitive Load (ECL)

ECL_t = 0.45 * Flatency + 0.35 * Jcursor + 0.20 * Bbacktracking

BUG-001 (P0): In-Flight State Reconciliation

The Problem & Actual Result

While an asynchronous LLM AST patch was streaming (~400ms), the user typed: "Antigravity QA automated verification string" (42 chars). Upon patch arrival, naive 1-way DOM mount wiped the input back to empty string ""!

Violation: Quality Invariant I1 (Zero Data Loss) FAIL

The 3-Way Reconciler Fix

Implemented AsyncStateReconciler.merge_inflight_keystrokes() which prioritizes active dirty input buffers:

State_final(k) = State_dirty(k) if k ∈ DirtyKeys else AST_incoming(k)

Verified: 100% Keystroke Preservation in TC-EDGE-004

BUG-002 (P1): Eliminating Layout Oscillation

The Problem: UI Thrashing

Synthetic cursor jitter produced ECL fluctuating across threshold 0.70 (0.69 ↔ 0.71). The layout mutated between monolithic view and progressive wizard 6 times in 1,200ms, creating severe screen flicker.

Violation: Quality Invariant I3 (Anti-Oscillation) FAIL

The Solution: Schmitt Trigger Hysteresis

Configured dual thresholds with temporal lockout:

  • Trigger Threshold: τ_high = 0.70
  • Reset Threshold: τ_low = 0.55 (Deadband: 0.15)
  • Cooldown Lockout: t_cooldown = 3,000 ms

Verified: 0 Thrashing Events in TC-UNIT-004
